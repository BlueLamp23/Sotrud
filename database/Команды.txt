Команды
.help	Показывает список всех доступных команд консоли.
.exit или .quit	Выход из консоли SQLite обратно в Windows.
.tables	Показывает список всех созданных таблиц в текущей базе.
.schema	Показывает SQL-код (структуру), которым были созданы таблицы.
.schema имя_таблицы	Показывает структуру только одной конкретной таблицы.
.mode	Настройка внешнего вида таблиц при выводе. (Например, .mode column делает ровные колонки, .mode box — красивые рамки, .mode csv — формат CSV).
.headers on	Включает показ названий колонок (заголовков) над данными. .headers off — выключает.
.read имя_файла	Выполняет SQL-скрипт из указанного файла 
.databases	Показывает, к каким файлам баз данных сейчас подключена консоль.
.open имя_бд	Открыть другую базу данных 
.backup имя_файла	Создает резервную копию текущей базы.
.import файл таблица	Загружает данные из CSV-файла в таблицу.
.output файл	Перенаправляет результат запросов в текстовый файл вместо экрана. .output stdout возвращает вывод обратно на экран.
